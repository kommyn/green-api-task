# Фронтенд реализация чатов Green API

Реализация системы текстовых чатов Telegram с возможностью отправлять сообщения пользователям по их номеру телефона с использование Greep API

## Запуск

### Локальный запуск

Установите зависимости:

```bash
yarn install
```
Запустите dev-сервер:
```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:5173.

### Локальный запуск в Docker

Чтобы собрать и запустить приложение с использованием Docker:

```bash
docker build -t my-app .
docker run -p 3000:3000 my-app
```

Запущенный фронт будет доступен по адресу http://docker-url:3000, где docker-url - адрес по которому запущен докер. Для докера в системе - localhost

## Описание приложения

Само приложение состоит из двух экранов:
1. Экран логина, в котором нужно ввести idInstance и apiTokenInstance инстанса
2. Экран чатов, который можно разделить на две части:
    - Слева - список существующих чатов. По клику на чат открывается окно конкретного чата. Внизу имеется кнопка "Создать чат", по нажатию на которую открывается модалка, в которой предлагается ввести номер телефона пользователя, которому нужно написать
    - Справа - чат, в котором можно отправлять, а также принимать текстовые сообщения. В случае обычного чата это работает так же как в обычном мессенджере. В случае созданного по номеру телефона чата логика несколько иная - чат существует только пока он открыт. Соответственно отправка/получение сообщений работают только на время использования чата
